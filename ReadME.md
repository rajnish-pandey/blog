# Rajnish Pandey — Portfolio

A modern, responsive portfolio website built with **React** and **Vite**.

## 🚀 Tech Stack

- **React** — UI framework
- **Vite** — Build tool
- **CSS** — Custom design system with dark/light theme support
- **GitHub Pages** — Hosting via `gh-pages` branch

## 🛠️ Development

```bash
npm install
npm run dev
```

## 🌐 Deployment

```bash
npm run deploy
```

This builds the project and pushes to the `gh-pages` branch automatically.

**Live site:** [rajnish-pandey.github.io/blog](https://rajnish-pandey.github.io/blog/)
